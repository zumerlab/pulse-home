# Demo homes: origin and license

The data in `homes/` and the entity behaviour in `entities.ts` come from the
Home Assistant frontend, the same code that runs
[demo.home-assistant.io](https://demo.home-assistant.io):

- `homes/<id>.ts` ← `demo/src/configs/<id>/entities.ts` (and `areas.ts` for
  `home`), with the names the frontend localizes written out in English;
- `homes/energy.ts` ← `demo/src/stubs/entities.ts`;
- `entities.ts` ← `src/fake_data/entities/*.ts`, ported to Pulse's style, with
  the colour maths of lights reduced to what Pulse shows and an `update` entity
  added.

The files in `homes/` are generated by `scripts/import-homes.py` from a
checkout of the frontend repository (`--check` compares without writing).
